# Чек-лист приёмки отчёта руководителю

Блокирующий: отчёт уходит, только когда каждый пункт закрыт «да» или согласованным отступлением.

## Объём и структура
- [ ] Одна страница, читается за пять минут.
- [ ] Ключевых показателей — пять–семь, не больше.
- [ ] Каркас совпадает с прошлым выпуском: руководитель находит то же на том же месте.

## Отклонения
- [ ] Три–пять отклонений, вышедших за согласованный коридор, — не все подряд.
- [ ] У каждого — величина в деньгах и база сравнения, не только проценты.
- [ ] У каждого — причина от владельца статьи или явная пометка «причина не установлена».
- [ ] Факт и гипотеза разделены.

## Проверяемость
- [ ] Контроли конвейера пройдены (`output/controls.md`).
- [ ] Автоматическая слепая проверка — расхождений нет (`output/verification.md`).
- [ ] Слепая проверка агентом — расхождений нет, протокол приложен.
- [ ] Каждое ключевое число стоит на своём месте: колонка, период, знак (это автоматика не решает).
- [ ] Указаны источник и дата среза; есть методические оговорки.
- [ ] Расхождения с прошлым выпуском объяснены.

## Язык и оформление
- [ ] Деньги — раньше процентов; знак понятен без пояснений.
- [ ] Термины — как в методике, без внутренних названий файлов и скриптов в тексте для руководителя.
- [ ] Отчёт просмотрен глазами: на телефоне и в тёмной теме читается.
- [ ] Ничего не выдумано.

## Итог
- [ ] Прочитано «глазами въедливого подчинённого»: к чему придерётся рецензент?
- [ ] Записаны три фразы, которые руководитель скажет на совещании после чтения.
