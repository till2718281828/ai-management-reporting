### Расхождение: чистая прибыль за 9М2026 в верхней плитке
- **Где:** в `output/index.html` (строка 32) стоит `<span data-r="R0454" data-f="mln">629,8</span>`.
  В таблице P&L (строка 38) у того же id R0454 правильно стоит 619,8.
- **Откуда моё число:** это сумма ног по счёту 99 за январь–сентябрь 2026, она равна 619 825 276,51 ₽.
  Тот же результат даёт P&L: прибыль до налога 826,4 минус налог на прибыль 206,6 = 619,8 млн ₽.
- **Что ещё затронуто:** рентабельность 13,6 % и изменение −0,2 % в этой же плитке сходятся с
  пересчётом. Неверна только сама сумма.

### Остальные сверки
- **Чистая прибыль и счёт 99.** Чистая прибыль каждого из 21 месяца равна сумме ног по счёту 99 за
  месяц, разница 0,00. За 9 месяцев: 619 825 276,51 (2026) и 621 256 665,99 (2025).
- **Разноска.** Все ноги по счетам результата разнесены маппингом, неразнесённых нет.
- **Реестр.** Я пересчитал все 495 строк `registry.csv` по их ключу: значения по месяцам и
  нарастающим итогам, изменение, изменение %, рентабельность, отклонение сверх роста выручки.
  Расхождений 0, дублей ключей нет.
- **HTML.** Все 158 чисел из `<span data-r>` отформатированы мной по методике: млн с одним знаком,
  округление половина вверх, флаги neg, abs и +. Не совпало только R0454 в плитке. Все форматы
  допустимы по таблице методики.
- **SHA-256.** Канонический хэш всех четырёх исходников совпал с `manifest.json`, число строк тоже:
  journal 2405, accounts 24, mapping 35, commentary 4.
- **Числа на своих местах.** Каждая ячейка таблицы P&L проверена скриптом: строка соответствует
  показателю, колонка — мере и периоду (9М2025, 9М2026, Δ, Δ %, 2025-09, 2026-09, Δ % месяца).
  Несоответствий нет. В плитках и абзацах про отклонения (Материалы, Ремонты, Прочие доходы и

### Что запускал
Всё — интерпретатором `.venv\Scripts\python.exe -I` этого репозитория.
- `<temp>\blind\recalc.py` — хэши, ноги, разноска, P&L, нарастающие итоги, контроль по счёту 99,
  сверка всего реестра и всех span в HTML. Выгрузка — `spans.json` в той же папке.
- Однострочники `-c`: текстовый вид HTML, проверка ключей по колонкам таблицы и по фразам, чтение
  `report.xlsx` через openpyxl.
- Bash-команды `head`, `cut`, `grep` для просмотра исходников.
